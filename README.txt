NARROWBORNE — site estático leve

Arquivos principais:
- index.html
- styles.css
- script.js
- assets/

Para testar: abra index.html no navegador.
Para publicar no GitHub Pages: envie todos os arquivos mantendo esta estrutura e defina a branch/pasta como fonte do Pages.
Mantenha a pasta admin somente no seu PC enquanto ela não tiver login seguro.

O site não usa bibliotecas externas, fontes externas ou banco de dados. O carrinho funciona no navegador e o botão final abre o checkout externo configurado no painel ADM.
O atendimento virtual funciona no próprio navegador, mantém o histórico durante a navegação e transfere o cliente para o WhatsApp com o contexto da conversa.

Para configurar o Mercado Pago:
1. Na pasta separada PAINEL-ADMIN-SOMENTE-PC, abra admin/index.html.
2. Entre em Pagamento.
3. Cole o link de pagamento/checkout pronto.
4. Baixe o novo store-data.js e publique no GitHub.

Para configurar o atendimento:
1. Na pasta separada PAINEL-ADMIN-SOMENTE-PC, abra admin/index.html e entre em Atendimento.
2. Informe o WhatsApp oficial, horários e mensagens.
3. Edite as perguntas frequentes, respostas e palavras-chave.
4. Baixe o store-data.js atualizado e publique no GitHub.
